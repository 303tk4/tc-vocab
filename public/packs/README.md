# 単語集（単語パッケージ）の出典とライセンス

このフォルダの単語集（`*.json`）は、アプリのプログラムとは別の条件で提供しています。リポジトリ直下の `LICENSE`（MIT License）は、このフォルダには適用されません。

| 内容                                | 出典・作成者                                                                                          | ライセンス                                                                                             |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 語の選定と級（タグ `TBCL:1級` など） | 國家教育研究院「臺灣華語文能力基準」詞語表（<https://coct.naer.edu.tw/page.jsp?ID=41>）              | 出典の条件に従う                                                                                       |
| 注音（拼音は注音から変換）          | 中華民國教育部《重編國語辭典修訂本》（<https://dict.revised.moe.edu.tw/>）                           | [創用CC 姓名標示-禁止改作 3.0 臺灣](https://creativecommons.org/licenses/by-nd/3.0/tw/)                  |
| 意味・例文・タグ                    | 開発者（303tk4）が AI を使って作成                                                                    | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)（© 2026 303tk4）                              |

意味・例文には AI による下書きを多く含み、誤りがありえます。無保証で提供します。

作り方は [scripts/packs/README.md](../../scripts/packs/README.md) にあります。
