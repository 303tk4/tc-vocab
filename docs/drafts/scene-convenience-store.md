# 場面別会話の試作：コンビニ（日本語版・下書き）

- 状態：AI（Claude）による下書き。台湾の人による確認はまだ。
- 目的：仕組みを作る前に、内容が実用に耐えるかを確かめる。
- 読み（注音・拼音）は、本番のデータを作るときに単語集と同じスクリプト（`scripts/packs/lib/zhuyin.mjs`）で付ける。この下書きには載せない。
- 種類 **R**（respond）：店員のセリフを見て（聞いて）答える。パターン1。
- 種類 **S**（say）：言いたいことを見て、中国語で言う。パターン2。
- ID は全場面で共通の項目の一覧の ID（仕様書 18.5）。ほかの場面で同じセリフを使うときは、この ID を指す。
- 「コンビニ」欄が「出題しない」の項目は、項目の一覧には置くが、コンビニの場面では出題しない（ほかの場面で使う）。
- 問題文は訳文の形にせず、「〜と伝えたい」のように意図として書く（答えのヒントにならないように）。

## 確かめたいこと

1. 台湾のコンビニで実際にこう言うか（特に r004・r005・r013・r019・s008・s013）。
2. 1問の分量（回答例2〜3個と補足）は、学習の画面で読むのにちょうどよいか。
3. 「返事はしなくてよい」という問題（r020）は、回答例を空にして補足で示す形で残す（決定）。
4. 「歡迎光臨」（r001）はコンビニではあまり言われないため、コンビニの場面では出題しない。項目の一覧には残し、ほかの場面（飲食店など）で使う（決定）。
